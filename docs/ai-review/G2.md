# AI Code Review — Giorno 2
1. response_model: presente su ogni endpoint (chat, glossary, categorize, import, health).
2. Errore: i servizi sollevano errori di dominio (InvalidFileError, NotFoundError) e l'handler li
   traduce nella busta; nessuna HTTPException nei servizi, quindi sono richiamabili da uno script.
3. Validazione: nei modelli Pydantic (Field(gt=0), pattern della valuta, validatore della data), non
   in catene di if negli endpoint.
4. Carico: l'import legge tutto il file in memoria con file.read() e non ha un limite di dimensione.
   Un file dieci volte più grande occupa dieci volte la memoria e blocca il worker. Da correggere con
   un limite sulla dimensione e una lettura a blocchi.
5. Non corretto, per scelta: il categorizzatore usa parole intere ed è fatto per l'italiano; una
   descrizione con parole attaccate («BonificoEnel») non scatta. Basta per oggi: dal Giorno 4 la
   classificazione la fa un modello.
